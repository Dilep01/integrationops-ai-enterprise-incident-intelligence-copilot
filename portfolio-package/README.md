# IntegrationOps AI portfolio package

This folder is a portable handoff for adding IntegrationOps AI to a separate portfolio project.
It contains copy, structured metadata, visuals, and a demo narrative derived from the working
repository. It does not change another portfolio.

## Start here

- `project.json`: machine-readable project facts for a portfolio card or project page
- `case-study.md`: long-form case study
- `demo-script.md`: a four-minute product walkthrough
- `resume-bullets.md`: evidence-based resume options
- `interview-talking-points.md`: design decisions and honest limitations
- `integration-guide.md`: how to move this package into another site
- `verification.md`: claims and the local evidence behind them
- `assets/cover.svg` and `assets/cover.png`: 1200 x 630 project cover
- `assets/architecture.svg` and `assets/architecture.png`: system architecture
- `screenshots/investigation-console.png`: real console state loaded from the local application
- `screenshots/api-documentation.png`: real FastAPI documentation page

## Recommended portfolio card copy

**IntegrationOps AI**

An evidence-grounded incident intelligence copilot that combines hybrid RAG, read-only
operational agents, citation validation, and approval-gated remediation for enterprise
integration failures.

**Tags:** GenAI, Agentic AI, RAG, LangGraph, FastAPI, Qdrant, Ollama, React

## Claim boundary

The application uses synthetic enterprise data and a local Integration Runtime Simulator. The
retrieval metrics are from the included 10-case synthetic benchmark, not production accuracy.
No SAP, bank, identity-provider, or monitoring system is connected.

Repository: https://github.com/Dilep01/integrationops-ai-enterprise-incident-intelligence-copilot
